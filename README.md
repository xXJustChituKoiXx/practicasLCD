# **INTRODUCCIÓN A LA CIENCIA DE DATOS (ICD)**

### **Escuela Superior de Cómputo (ESCOM) - IPN**

Repositorio oficial que contiene las prácticas, códigos fuente y material de estudio desarrollado para la unidad de aprendizaje de **Introducción a la Computación y el Desarrollo**.

## **Descripción General**

Este repositorio recopila los fundamentos de programación, manejo de scripts y análisis inicial de datos trabajados durante el primer semestre en la ESCOM, utilizando lenguajes y herramientas como Python y Jupyter Notebooks.

## **Estructura del Repositorio**

El contenido se encuentra organizado de la siguiente manera:

### **1. Archivos Raíz**

* `comd_pd.ipynb` — Cuaderno de trabajo enfocado al manejo y análisis de datos.
* `practica_if_ICD.py` — Script de práctica sobre estructuras condicionales en Python.
* `variables.py` — Módulo o script introductorio sobre tipos de datos y declaración de variables.

### **2. Examen 1**

* `dataset_examen.csv` — Conjunto de datos utilizado para la evaluación del primer parcial.
* `examen.py` — Solución en código implementada para el primer examen parcial.

### **3. Examen 2**

* `examen.ipynb` — Cuaderno interactivo correspondiente a la evaluación del segundo parcial.
* `vgsales.csv` — Conjunto de datos sobre ventas de videojuegos empleado para el análisis del segundo examen.

## **Requisitos de Ejecución**

* Intérprete de Python (versión 3.8 o superior).
* Entorno para ejecución de Jupyter Notebooks (`jupyterlab` o extensión compatible).
* Librerías estándar para análisis de datos (como `pandas`) en caso de procesar los archivos CSV.

## **Instrucciones de Uso**

Para ejecutar los scripts de Python de manera directa desde la terminal:

```bash
python nombre_del_archivo.py
```

Para abrir y trabajar con los cuadernos interactivos:

```bash
jupyter notebook
```
